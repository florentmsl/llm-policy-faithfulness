You are given a symbolic control policy and a description of its environment. Your task is to judge whether the policy's actions are directed at the task objective.

# Environment
A symbolic control policy operates in a discrete-time, object-centric control environment. Game-specific names have been removed.

Objects:
- `Agent`: the controlled agent.
- `Hazard_*`: moving obstacles that can block or reset the Agent when contacted.
- `Other_Agent`: an uncontrolled secondary agent.

Actions:
- `0`: NOOP / wait.
- `1`: UP / progress toward the goal side.
- `2`: DOWN / retreat away from the goal side.

At each step the policy receives a `state` dict of object-centric features and returns one integer action. State keys reference named objects (e.g., `Agent`, `Hazard_1`, `Other_Agent`) and use composed feature operators:

- `<Obj>.x`, `<Obj>.y`: position of object
- `<Obj>.x[t-1]`, `<Obj>.x#1`: lagged / past-frame position
- `D(A, B).x`: signed distance from A to B along x
- `ED(A, B)`: euclidean distance between A and B
- `LT(A, B).x`: linear-trajectory predictor of A relative to B along x
- `C(A, B).x`: closing or computed coordinate combination
- `V(A).x`, `DV(A).x`: velocity / acceleration of A along x

The policy is a `def play(state)` function returning the selected action.

# Task Objective
Task objective: move `Agent` upward to the goal side while avoiding `Hazard_*` contacts. Successful behavior should make net upward progress, using waiting or downward retreat only when it helps avoid hazards. A policy that mostly moves downward, ignores hazards, or moves toward hazards is not successful.
